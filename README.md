## ✨ Features

- **🎨 Modern & Premium Design**: A highly polished, aesthetic user interface avoiding run-of-the-mill templates.
- **✨ Dynamic Animations**: Smooth interactions and scrolling effects powered by [GSAP](https://gsap.com/) and [Framer Motion](https://motion.dev/).
- **📱 Fully Responsive**: Flawless experience across desktop, tablet, and mobile viewing environments.
- **⚡ Supercharged Performance**: Built on Next.js 16 utilizing the App Router to maximize speed and SEO.
- **✉️ Seamless Contact**: Direct messaging integrated using EmailJS.

## 🛠️ Tech Stack

This project was built with a bleeding-edge modern web stack:

- **Framework**: [Next.js 16](https://nextjs.org/)
- **Core UI**: [React 19](https://react.dev/) 
- **Language**: [TypeScript](https://www.typescriptlang.org/)
- **Styling ecosystem**: [Tailwind CSS v4](https://tailwindcss.com/), [DaisyUI](https://daisyui.com/), and [clsx](https://github.com/lukeed/clsx) / `tailwind-merge` for adaptive styling.
- **Animations & Graphics**: [GSAP](https://gsap.com/), [Framer Motion](https://motion.dev/), [Lottie React](https://lottiereact.com/), and `ogl`.
- **Icons**: [Lucide React](https://lucide.dev/) & [Tabler Icons](https://tabler.io/icons).

## 🚀 Getting Started Locally

Want to run this project on your local machine? Follow these simple steps:

### Prerequisites
Make sure you have Node.js installed along with your favorite package manager (`npm`, `yarn`, `pnpm`, or `bun`).

### Installation process

1. **Clone the repository:**
   ```bash
   git clone https://github.com/mazharul90007/portfolio.git
   cd portfolio/mi-sourabh
   ```

2. **Install project dependencies:**
   ```bash
   npm install
   # or yarn install / pnpm install / bun install
   ```

3. **Fire up the development server:**
   ```bash
   npm run dev
   # or yarn dev / pnpm dev / bun dev
   ```

4. **Visit the app:**
   Open [http://localhost:3000](http://localhost:3000) in your selected web browser to see the result.
